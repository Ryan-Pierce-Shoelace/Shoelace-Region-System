# Shoelace Region System
A lightweight, performant 2D grid system for Unity with chunking support and spatial query tools. Designed for tile-based games, strategy games, and any project requiring efficient spatial organization.
## Requirements

- Unity 2021.3 or higher
- [Shoelace Utilities Package](https://github.com/Ryan-Pierce-Shoelace/Shoelace-Utilities)

# Installation

1. Install required Shoelace Utilities package via Package Manager (Git
   URL): `https://github.com/Ryan-Pierce-Shoelace/Shoelace-Utilities.
2. Add this package via Package Manager using: `https://github.com/Ryan-Pierce-Shoelace/Shoelace-Region-System`
